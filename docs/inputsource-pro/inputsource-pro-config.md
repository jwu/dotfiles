# Input Source Pro 配置说明

Input Source Pro 是一个 macOS 输入法自动切换工具。规则由应用自己持久化在 macOS 的偏好设置
里，没有纳入本仓库——换机器要按本文重新点一遍。截图的文字内容已并入下面两节。

以下设置对应 2.9.0 (605)。

## 安装方法

使用 Homebrew 安装：

```bash
brew install --cask input-source-pro
```

## 通用

「通用」页（`通用` 分组）：

| 项 | 值 |
| --- | --- |
| 默认输入法 | 适用于所有应用和网站 → `ABC` |
| 输入法恢复策略 | 切换回应用或网站时 → **总是切换至默认输入法**（不是「恢复上次使用的输入法」） |
| 默认功能键 | 将 F1、F2 等用作标准功能键，而不是媒体键 → 关闭 |
| 提示触发规则 | 长按鼠标左键时显示 ✅、切换输入焦点时显示 ✅（需要增强模式）；切换输入法时显示 ☐、切换应用时显示 ☐ |

选「总是切换至默认输入法」是这套规则的前提：焦点一换就回到 `ABC`，中文只在需要时手动切。

## 应用规则

「应用规则」页给单个应用覆盖上面的全局设置。图里列出的应用按名称排序：

```
Google Chrome   Logseq   Neovide   Numbers 表格   Obsidian   WezTerm   Zed
屏幕共享   微信   日历   访达   音乐   预览   飞书
```

底部「添加运行中的应用」保持勾选，新应用启动时可以直接加进来。

选中条目右侧是它的三项设置：默认输入法 `ABC`、功能键「使用全局设置」、输入法恢复策略与
全局一致（总是切换至默认输入法）。「隐藏输入法提示」与「强制使用英文标点符号」默认不勾。

这里的价值在于**例外**：列出来的应用是要单独定的那些，其余应用走全局规则。

## 隐藏顶部语言栏（可选）

如果想隐藏 macOS 顶部的语言指示栏（显示当前输入法的那个），可以执行以下命令并注销重新登录：

```bash
defaults write kCFPreferencesAnyApplication TSMLanguageIndicatorEnabled 0
```

注销重新登录后生效。
